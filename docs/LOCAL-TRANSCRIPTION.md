# Local transcription fallback — September 15, 2026

Recommendation: integrate **Whisper large-v3-turbo through WhisperKit** as Chup!'s first dependable English/Dutch offline fallback on macOS 15+. Benchmark **Parakeet TDT 0.6B v3** as the latency-oriented alternative and **Qwen3-ASR 1.7B** as the newer quality challenger. This is an engineering recommendation based on language coverage, native integration and deployment fit, not a claim that one model wins every 2026 accuracy benchmark.

Implementation follow-up: the app now integrates the pinned WhisperKit runtime and a verified 630 MB Turbo model/tokenizer download. Dictation supports local-only processing and sequential cloud-to-local fallback. The SoundAnalysis accidental-clip classifier remains separate. This applies to dictation; meeting diarization, summaries and conversational voice retain their separate provider paths. See VALIDATION.md for the actual model qualification and installed-build receipt.

## What was actually checked locally

The host reports Apple M5 Max and 128 GiB unified memory. A read-only Swift query returned `SpeechTranscriber.isAvailable == true`. Supported locales included English, German, Spanish, French, Italian, Japanese, Korean, Portuguese, Cantonese and Chinese variants, but no `nl` locale. Installed locales were English variants. No speech permission was requested and no ASR model assets were downloaded by that query.

Evidence: `.artifacts/check-local-speech.swift` and `.artifacts/local-speech-availability.log`. Availability is queried at runtime; these results are specific to this Mac/OS, not an immutable global language list. SDK declarations confirm SpeechTranscriber requires macOS 26+.

No head-to-head Whisper/Parakeet/Qwen WER, memory or latency results are claimed. Comparing NVIDIA GPU throughput, a vendor benchmark and Apple's undocumented performance would not establish a fair Mac ranking.

## Fallback behavior and remaining design requirements

1. **Install before promising offline readiness.** Offer a one-time model download in setup/Dictation settings, show actual download size/progress, verify the pinned artifact and run a tiny local inference test. Mark Offline ready only after this succeeds. Keep an installed model available when cloud credentials are absent. Do not require a first network download during an outage.
2. **Auto / Local only / Cloud modes.** Auto tries the configured cloud service with bounded timeouts and falls back to the installed local engine on missing configuration, connection errors, 429/5xx or an unavailable model. Cloud disabled must never trigger an upload. Cancellation, invalid audio and a deliberate user stop are not fallback triggers. Missing local assets retain the recording with a clear recovery action.
3. **One output and one insertion.** A generation/request ID owns the winning result; late cloud output must not insert again or replace user edits. Store provider/model/language and transcript revisions. Mark possibly charged cloud attempts unconfirmed instead of automatically paying for them again. Local work gets its own resumable job linked to the original audio.
4. **Local text remains useful if cleanup fails.** Commit raw local transcription first. If cloud polishing/selected-text editing is unavailable, offer the local transcript plainly; do not claim polishing or translation succeeded. Existing snippets and preferred spellings can run locally.
5. **Keep capture independent.** Analyze the owner's saved chunks, use bounded resampling and a separate worker, and suspend optional refinement under recording backpressure. Model loading/inference never runs in an audio callback. Cache/warm models conservatively, react to memory pressure and verify performance on 16 GB Macs as well as this 128 GB machine.
6. **Meetings need more than ASR.** Transcribe separate tracks with absolute offsets. Local speaker diarization is another component and must preserve manual speaker corrections. Local summaries and a conversational assistant need their own language model, tools and playback policies; a Whisper fallback does not replace GPT-Live-1 full-duplex conversation.

## Benchmark before selecting a faster default

Use the same pinned audio corpus for all candidates: English/Dutch short dictations, yes/no/nee, names and product vocabulary, numbers and negation, self-corrections, accents, soft speech, keyboard taps/fan noise, overlapping speakers and two-hour separate-track calls. Measure cold-start and warm latency, real-time factor, peak memory/energy, WER plus critical name/number/negation errors, silence hallucinations and word/segment alignment. Test with the network disconnected and with cloud timeouts racing a local completion. Include 16 GB M1/M2-class systems and this M5 Max; do not pick a universal default from a single high-memory Mac.

## Current implementation details

Settings → Dictation offers Cloud with local fallback (default), Local only, and Cloud only. A 20-second cloud request timeout bounds individual dictation requests; network/provider failures fall back sequentially to local inference. Missing cloud configuration or disabled cloud processing goes directly local in Auto. Local only never calls cloud cleanup. Model setup is an explicit download; inference uses a strict local tokenizer adapter that cannot fall through to a network download. Each artifact is pinned by revision, length and SHA-256 in `App/Resources/LocalSpeechModel.json`. Completed verified download files survive cancellation for reuse on retry. Download and installed-model removal are separate from recording deletion.

Audio is decrypted and resampled in bounded journal windows on a dedicated actor, never written to a plaintext temporary audio file. The SDK does not open a microphone. Raw text and provider metadata commit before optional cloud cleanup. Local text uses existing deterministic snippets/spellings but does not claim AI cleanup. Local selected-text editing saves the spoken instruction and refuses to return it as replacement text. Cancellation prevents final writes/insertion; cloud fallback discards partial cloud text and produces one result. Existing history entries can use Retry audio without changing their saved language or preferences.

The current local model handles dictation journals up to 35 seconds each (capture rotates at 30 seconds). Cross-journal sentence boundaries can still reduce accuracy; overlapping-window reconciliation and local meeting diarization remain separate work. No universal Mac benchmark ranking is claimed.
