# Ghost Pepper: lessons for Chup!

Implementation follow-up: the next increment adds persistent stage traces and a working local comparison lab for Whisper Turbo and Parakeet v3, including verified model download/removal and offline English/Dutch synthetic qualification. See SETUP.md and VALIDATION.md. The remaining rows below are still candidates rather than completed integrations.

Reviewed September 15, 2026, at commit `5a5b53aadbc1c1f76968cd1c8a9aff690d076887`. This is a source review against Chup! build 28, not a performance benchmark or certification of Ghost Pepper. Source was cloned into the ignored `.artifacts/references/ghost-pepper` directory; its app, build scripts and models were not executed. No Chup! runtime changes are included in this review.

## Recommended order

| Priority | Learning | Application in Chup! | Acceptance criterion |
| --- | --- | --- | --- |
| P0 | Per-stage performance trace | Track shortcut receipt, actual first microphone packet, capture stop, ASR, cleanup, insertion attempt and verified result under one session ID. Expose concise stage timings in Advanced diagnostics. | Local/cloud/fallback/cancelled attempts have complete or explicitly missing stages; diagnostics contain no dictated text, field contents or audio. Use monotonic clocks. |
| P1 | Transcription Lab | Replay one chosen recording against candidate models, showing original/candidate text, timing and speaker segments without replacing history or inserting text. | English/Dutch fixtures cover names, numbers, negation, quiet speech, noise, code switching and multiple microphones. Report cold/warm latency, memory and transcription errors; require explicit use of a candidate result. |
| P1 | FluidAudio evaluation | Benchmark Parakeet v3 and Qwen3-ASR 0.6B alongside our existing Whisper Turbo. Evaluate Silero VAD and local diarization as separate capabilities. | Pin converted artifacts and licenses; measured results on 16 GB hardware and this Mac; cancellation and network-disabled inference; uncertain VAD never deletes audio or silently drops quiet speech. |
| P2 | Offline text cleanup | Add a bounded local cleanup provider, evaluating the compact Qwen 3.5 models used upstream. Preserve our cleanup modes, dictionary and raw transcript. | Verify names, numbers, negation and English/Dutch meaning; reject instruction following, unusable output and unsupported rewriting; fall back to the committed raw transcript on timeout/failure. |
| P2 | Correction suggestions | Offer to save repeated spelling corrections as dictionary aliases. Start with corrections made inside Chup!, where the user explicitly edits the transcript. | Suggested replacements require confirmation, have provenance and are editable/deletable. Any later external-field observation is opt-in, short-lived, scoped to the original insertion and excludes secure fields. |
| P2 | Better meeting prompts | Add cautious window-title hints to our Core Audio activity signal, primarily to suggest a useful meeting title and exclude app home/settings windows. | Title alone cannot prove a call or a browser tab's identity. Keep debounce, snooze/deduplication, ten-second timeout and explicit recording action. |

## Source evidence and fit

**Diagnostics.** [PerformanceTrace.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Debug/PerformanceTrace.swift) records hotkey-to-mic, transcription, cleanup sub-stages, paste and total durations. This directly addresses our recent difficulty distinguishing no microphone input, model work and unconfirmed insertion. Chup!'s existing diagnostics export contains status/counts but no full per-dictation stage trace. We should carry the idea into our allowlisted diagnostics, using monotonic timing rather than copying its wall-clock implementation.

**Local model comparison.** [SpeechModelCatalog.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Transcription/SpeechModelCatalog.swift) describes WhisperKit, FluidAudio, MLX Audio and system SpeechAnalyzer backends. [TranscriptionLabController.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Lab/TranscriptionLabController.swift) keeps experimental transcripts and ASR/cleanup timings separate from the saved entry and exposes diarization views. This is a practical evaluation workflow; catalog labels and advertised speed are not evidence that a model beats Chup!'s current Whisper large-v3-turbo on Dutch.

**Speech detection and speakers.** The upstream dependency [FluidAudio](https://github.com/FluidInference/FluidAudio) exposes VAD, ASR, diarization and embeddings. Model-family language coverage is documented by [NVIDIA Parakeet v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) and [Qwen3-ASR 0.6B](https://huggingface.co/Qwen/Qwen3-ASR-0.6B); exact Swift conversions still require qualification. These candidates expand the research already recorded in LOCAL-TRANSCRIPTION.md. Waveform energy and speech probability should remain distinct UI/processing concepts. A speech model cannot recover audio physically absent from a closed-lid microphone.

**Local cleanup.** [TextCleanupManager.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Cleanup/TextCleanupManager.swift) has pinned GGUF URLs, expected hashes/sizes, a compact Qwen 3.5 0.8B option, larger alternatives and bounded calls. [TextCleaner.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Cleanup/TextCleaner.swift) constructs cleanup prompts and strips model reasoning markup. Chup!'s current local fallback supplies transcription and deterministic personalization; local generative cleanup is a real additional capability. Prompt instructions and output sanitization alone do not establish meaning preservation.

**Personalization.** [PostPasteLearningCoordinator.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Cleanup/PostPasteLearningCoordinator.swift) polls a pasted field briefly and waits for edits to settle before learning small replacements. Chup! should begin with explicit in-app correction suggestions. Watching unrelated typing would exceed the intended scope of a personal dictionary.

**Meeting hints.** [MeetingWindowHeuristics.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Meeting/MeetingWindowHeuristics.swift) excludes known home/settings and internal Zoom window titles and cleans title suffixes. Its permissive treatment of other titles needs stronger gating in Chup!, particularly for browsers and localized applications.

## Parts that do not satisfy Chup!'s requirements as implemented

- **Paste confirmation and clipboard protection:** [TextPaster.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Input/TextPaster.swift) returns `pasted` when delayed Command-V is scheduled, and restores the old clipboard after a fixed delay without a pasteboard-generation guard in that flow. It also has an always-allowed application bypass. Keep Chup!'s original destination, secure-field, interaction/focus and clipboard-generation checks; copying this path would reintroduce risks we explicitly designed out.
- **Track labels are not person recognition:** [DualStreamCapture.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Audio/DualStreamCapture.swift) distinguishes microphone and system streams, described as Me/Others. It timestamps callback arrival with wall-clock elapsed time and returns full audio buffers. Chup! needs durable timestamped chunks, its shared audio owner and multiple speakers per track.
- **Dominant-speaker filtering is not meeting transcription:** [FluidAudioSpeechSession.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Transcription/FluidAudioSpeechSession.swift) can select a dominant speaker and transcribe retained spans. Do not apply that policy to meetings, where every participant matters. [SpeakerIdentityResolver.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/SpeakerIdentity/SpeakerIdentityResolver.swift) automatically matches/creates persistent voice profiles using embeddings; Chup! requires explicit enrollment, uncertain matches and deletion controls.
- **Summary prose is not evidence validation:** [MeetingSummaryGenerator.swift](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/GhostPepper/Meeting/MeetingSummaryGenerator.swift) generates chunked local Markdown summaries. Chup! needs transcript-backed factual items, null owners/dates when unknown, source navigation and validation before committing summaries. Local generation can be a provider behind that boundary.

## Reuse and next work

The [README](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/README.md) declares MIT, but the reviewed tracked tree contains no standalone LICENSE file. Record the exact provenance and obtain the full license/notice text before vendoring source; each runtime and converted model also has its own terms. The [project specification](https://github.com/matthartman/ghost-pepper/blob/5a5b53aadbc1c1f76968cd1c8a9aff690d076887/project.yml) uses forks for MLX Audio and LLM.swift, with the latter on a floating branch. Chup! should retain exact dependency pins and artifact verification.

First implementation slice: add privacy-preserving stage tracing and a small diagnostic view, keeping raw content out of exported traces. Second slice: build the local-model comparison harness and benchmark the candidates. Model selection and any default changes should follow those measurements. Later slices: calibrated VAD, local diarization, offline cleanup, then opt-in correction learning. UI design should keep these advanced controls in Settings/diagnostics while preserving Chup!'s compact dictation flow.
